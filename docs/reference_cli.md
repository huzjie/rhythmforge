# CLI 参考

```
rhythmforge [--config PATH] <command> [options]

commands:
  doctor    打印引擎装配信息
  demo      跑一次示例决策
  bench     跑基准评测套件（--seed）
  snake     贪吃蛇演示（--width/--height/--steps/--seed/--planner）
  plan      展示前瞻规划（--width/--height/--seed）
  serve     启动 HTTP 服务（--host/--port）
```
